# Du Bois Does Data: classroom lessons

Four lessons that take students inside W.E.B. Du Bois's hand-drawn data portraits from the 1900 Paris Exposition, then have them make their own.

## The lessons

1. **Become a Data Detective:** read a Du Bois chart closely and find what it argues.
2. **Seeing the Story of the Color Line:** the data behind the portraits and what it shows.
3. **Ask the Archive:** question Du Bois's own writing through a living archive, and check the answers against the source.
4. **Draw the Data:** make a Du Bois-style visualization from today's numbers.

Open `index.html` for the hub; each lesson is a single page that runs in a browser. Printable guides are included as PDFs.

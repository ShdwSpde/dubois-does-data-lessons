# Du Bois Does Data: classroom lessons

Four lessons that take students into W.E.B. Du Bois's hand-drawn data portraits from the 1900 Paris Exposition, then have them make their own.

## The lessons

1. Become a Data Detective: read one of Du Bois's charts closely and work out what it argues.
2. Seeing the Story of the Color Line: the data behind the portraits and what it shows.
3. Ask the Archive: question Du Bois's writing through a living archive, and check the answers against the source.
4. Draw the Data: make a chart in Du Bois's style from current numbers.

Open `index.html` for the lesson hub. Each lesson is a single web page that runs in a browser, and printable guides are included as PDFs.
